VELOOP Rewards — Exchange Center (HTML/CSS/JS)

How to run:
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

Features:
- Responsive dark VELOOP-style layout based on the supplied screenshot.
- Profile dropdown and balances.
- Three conversion options: 1,000 Gems → 100 VEs; 2,500 → 300; 5,000 → 700.
- Confirmation modal before converting.
- Front-end balance updates and conversion history.
- Data is demo-only and resets when the page is refreshed. No backend/database is connected.
